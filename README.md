# SolutionWCMD organization profile

This repository contains organization-wide GitHub configuration for **Solution-WCMD**.

GitHub renders the public organization profile from:

```text
profile/README.md
```

Profile-specific artwork and animated SVGs are stored under:

```text
profile/assets/
```

Keep the relative asset paths intact when moving or updating the profile. Visual and narrative assets are governed by [ASSET-NOTICE.md](ASSET-NOTICE.md).
